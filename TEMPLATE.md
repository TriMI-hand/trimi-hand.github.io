# Template source and attribution

Adapted from [SenseRoboticsLab/NAS-GS-Page](https://github.com/SenseRoboticsLab/NAS-GS-Page), commit `b424d2fe9458c60d597d3bd62f51e53c1f78da4e`.

NAS-GS-Page uses Roman Hauksson's [Academic Project Astro Template](https://github.com/RomanHauksson/academic-project-astro-template), originally adapted from Eliahu Horwitz's [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template) and Keunhong Park's [Nerfies project page](https://nerfies.github.io/).

This notice does not relicense the TRIMI research assets or third-party dependencies; their respective rights and licenses remain applicable.

Retained elements include Astro/MDX/React/Tailwind setup, the academic page shell, Noto Sans configuration, typography/layout styles, author/link/figure/highlighted-section components, and the reusable research component library. Changes replace NAS-GS content with TRIMI content, add the hardware viewer and teleoperation fade, adapt assets for subpath deployment, and add accessible fallbacks. NAS-GS authors, sonar imagery, claims, and research results are not included.
